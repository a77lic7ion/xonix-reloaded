# Google Flow Music Prompt Pack — Xonix

These prompts are designed for background music that supports concentration and short arcade rounds. Keep each result instrumental and loop-friendly; avoid audible vocals, spoken words, recognisable melodies, and abrupt hard endings.

| Use | Google Flow Music prompt |
|---|---|
| Title screen | **Instrumental title-loop for a 1984-style territory-capture arcade game. Slow 94 BPM minor-key analogue arpeggio, restrained FM electric piano, sparse square-wave bass pulses, soft tape hiss, and a confident but slightly mysterious melody. Black-screen DOS arcade mood, not chiptune parody, no vocals, no sound effects, clean 45-second seamless loop, gentle fade-in and no final cadence.** |
| Main gameplay | **Instrumental gameplay loop for a precision arcade territory-capture game. 118 BPM, hypnotic mono-synth bass ostinato, dry electronic drum machine with soft kick and clipped clap, understated FM bell pattern, occasional short filtered noise sweep. Feeling: focused, geometric, calm under pressure, late-1980s computer arcade soundtrack. No vocals, no lyrics, no recognisable melody, no busy lead, no sound effects, 60-second seamless loop with no ending.** |
| High-risk / late level | **Instrumental escalation loop for a territory-capture arcade game in danger. 132 BPM, tense repeating minor-seventh synth pulse, faster sequenced bass, minimal gated percussion, subtle dissonant glassy FM accents, restrained analogue filter movement. Build suspense without becoming aggressive or cinematic. No vocals, no lyrics, no rock guitar, no orchestra, no sound effects, 45-second seamless loop, open-ended mix.** |
| Game over / score entry | **Short instrumental score-entry cue for a classic DOS arcade game. 76 BPM, reflective FM electric-piano chords, single warm synthesizer lead answering in short phrases, low square-wave bass, faint tape texture. Mood: measured disappointment but inviting another attempt. No vocals, no lyrics, no sound effects, 20-second cue that can loop quietly without a dramatic ending.** |

For a cohesive set, reuse the same **main gameplay** generation seed or sonic description for the high-risk version, then ask for a faster tempo and a darker harmonic variation. Keep sound effects separate from these music generations so gameplay feedback remains crisp.
